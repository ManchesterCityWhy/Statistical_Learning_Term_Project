# 统计学习开题报告 T1 LaTeX 修订稿

主文件为 `main.tex`，使用 XeLaTeX 或 Tectonic 编译，PDF 保持为 3 页。

请完整保留 `fonts/` 文件夹。项目使用随附的 Noto Serif SC 常规和粗体字体，无需另外安装中文字体；不要仅复制 `main.tex`。

XeLaTeX 建议编译两次，以正确生成交叉引用和参考文献编号。Tectonic 会自动执行所需的多轮编译。

本次修订针对中文缺字、乱码和空白的兼容性问题，仅修改字体配置与必要排版。研究内容、公式和参考文献保持原有讨论方案。

## 字体来源与许可

- 官方字体项目：https://github.com/notofonts/noto-cjk
- 常规字体：https://github.com/notofonts/noto-cjk/blob/main/Serif/SubsetOTF/SC/NotoSerifSC-Regular.otf
- 粗体字体：https://github.com/notofonts/noto-cjk/blob/main/Serif/SubsetOTF/SC/NotoSerifSC-Bold.otf
