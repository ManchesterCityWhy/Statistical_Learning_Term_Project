# K4 T1：第二轮优化结果

2026-11-24。仅进行内部实验，没有官方提交。目标为 70 分，退而求其次为 60 分。

## 结论

本轮最佳模型 `deconv3_mix1_bulk3` 的选模集得分为 **60.5004**。固定该候选后，三组新细胞审计分别为 **59.2722、60.1538、60.4818**，均值 **59.9693**。结果已接近 60，但没有达到 70，均值也没有严格超过 60。所有分数均为本地校准分数；隐藏 E12.5 的成绩与名次未知。

本轮比较了 94 个候选配置记录，包括重复的基线：36 个类型表达外推配置、36 个组成反卷积配置、6 个强迁移配置、16 个细化配置。选模只使用 development 分数。后续三组审计完成后，没有再调整参数。

## 方法

以源阶段各细胞类型的平均计数表达构造基因×类型矩阵。由允许使用的 E9.5/E14.5 bulk 计数估计可靠性收缩后的基因变化趋势，作用于源阶段群体均值，得到期望群体表达。随后进行非负最小二乘反卷积，并以 ridge 项约束比例偏离源阶段的程度。按推断比例对源细胞加权无放回抽样，再迁移 bulk 表达趋势，最后恢复每细胞计数总量 10,000 和 log1p 尺度。

最终选定的组成趋势强度为 3，组成混合比例为 1，表达趋势强度为 3。ridge 系数保持 10，不参与搜索。E10.5 的真实表达只用于评价与选模，真实细胞类型比例没有进入反卷积输入。

类型标签合并、加法/乘法外推最高达到约 54.84，弱于组成反卷积。将表达迁移强度提高到 10 或 20 后，部分候选降至约 53 或 35 分；强迁移不能继续带来提升。

## 审计设计与限制

- 所有显式实验种子为 42。细胞划分与组成候选抽样使用初始化后的连续随机数流；候选内部确定性指标共用相同评估设置。
- 先固定 development、ceiling、confirmation、confirmation ceiling 的细胞划分。
- 最终三组审计细胞从上述四组之外抽取，各组 target/ceiling 互不重叠。复用已经固定的预测，不在审计组上重新拟合。
- 各组仍来自同一官方发育阶段资源，不能当作独立胚胎重复；“新细胞”指未进入本轮前述划分，不代表它们从未被历史实验抽中过。
- 最佳反卷积解集中在少数类型，部分类型权重为零。例如开发阶段 ST 的目标权重约 42.4%，Endocardium 约 23.8%，AVC-CM 约 17.9%。这些是模型的抽样权重，不是推断正确的生物学真值；无放回抽样还受每类源细胞数量限制。
- E10.5→E12.5 的两天外推与开发阶段的一天跨度不同，且 E10.5 包含新的类型。即使本地得分提高，隐藏测试仍可能回落。

## E12.5 文件

本轮分别生成两个外推幅度版本，均从官方 E10.5 出发，使用同一已选方法及相同外部数据：

- `conservative_h1/E12.5_prediction.h5ad`：保留已验证的修正幅度，作为较保守的首选候选。h1 是修正倍率，不是预测目标；目标仍为 E12.5。
- `two_day_h2/E12.5_prediction.h5ad`：把组成趋势和表达趋势幅度乘以 2，作为两天线性延伸的备选。此规则没有 E12.5 验证分数，不能视为优于 h1。

两份均为 2,000×32,285，不包含细胞类型标签。每个目录含 manifest，记录预测哈希、外部文件哈希、归一化检查和配置。没有使用 E12.5 真值，没有官方格式检查或正式上传。

旧 `submission_01/E12.5_prediction.h5ad` 保留为对照，不覆盖。如果选择新模型手动提交，选择 Final test (P3) → T1:test；不要把 ZIP 或指标 CSV 当作预测上传。
