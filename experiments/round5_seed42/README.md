# 第五轮：E14.5 同平台锚点混合（2026-11-26）

> 本页为阶段性实验记录，文中的推荐方案是当时的候选。第二次正式提交采用[第九轮方案](../round9_seed42/README.md)，官方得分为 73.37。

## 结论

推荐的第二次官方提交是 `round5_anchor0.375_all_h1`：第四轮的 2,000 个细胞原样保留，再混入 1,200 个公开的 E14.5 野生型小鼠心脏细胞核（GEO GSE272154 / GSM8394736，和竞赛数据同为 10x Multiome、Cell Ranger ARC 2.0.2、mm10），锚点占 37.5%，共 3,200 个细胞。文件 SHA-256 为 `7855b636c13b7de3661f3588096cdaabebe34bd088a15599dce06251e7997ee0`，已通过 `validate_prediction`（T1:test 基因顺序、细胞数、非负有限）。

所有分数都是本地校准分（复制参考阶段 = 50，同阶段另一半细胞 = 100），不是榜单分。

## 选模规则和结果

规则在看复核集之前定好：在深度匹配代理的复核集上比第四轮（61.53）高 1.0 分以上，且原始设定不崩，才替换第四轮。

本地验证时源阶段是 E9.5，E10.5 位于 E9.5 到 E14.5 的五分之一处，锚点比例取 0.15（选模集上的最优值）。

| 代理（参考 → 目标） | 选模集 第四轮 | 选模集 +锚点 0.15 | 复核集 第四轮 | 复核集 +锚点 0.15 |
| --- | ---: | ---: | ---: | ---: |
| dm：深度匹配 E9.5 → E10.5 全体 | 63.06 | 68.31 | 61.53 | 67.42 |
| raw：原始 E9.5 → E10.5 全体 | 60.70 | 69.68 | 59.92 | 69.47 |
| h3：原始 E9.5 → 仅 E10.5 文库 3 | 64.65 | 69.89 | 64.85 | 70.07 |
| p8/all：参考 E8.5、源 E9.5 → E10.5 全体 | 68.71 | 77.04 | 67.43 | 76.32 |
| p8/deep：参考 E8.5、源 E9.5 → 仅文库 3 | 72.15 | 76.98 | 71.98 | 76.89 |

复核集只看了这一个配置一次。深度匹配代理上提高 5.9 分，五个代理全部提高 4.9 到 9.5 分，满足规则。

## 锚点比例怎么定到 0.375

- 一天的代理（时间比例 1/5 = 0.20）：最优比例 0.15 到 0.20，过了最优点掉得快（dm：0.15 → 68.3，0.30 → 63.5，0.40 → 58.0）。
- 两天的类比（源和参考都是 E8.5，目标 E10.5，时间比例 1/3）：最优比例 0.25 到 0.30，选模集和复核集一致。
- 最优比例约为时间比例的 0.75 到 0.9 倍。E12.5 在 E10.5 和 E14.5 正中间（0.5），取 0.75 × 0.5 = 0.375。这个数本身无法在本地验证。

## 试过但没采用的

| 尝试 | 结果 | 分数表 |
| --- | --- | --- |
| 只保留心脏类型细胞、粗类型比例外推、E8.5→E9.5 成熟度倾斜 | 都低于第四轮 10 分以上 | `scores/round5_exp1__scores.csv` |
| 反卷积改用 k-means 细胞状态；调趋势强度和 ridge | k-means 明显变差；调参在噪声内 | `scores/round5_exp2__scores.csv` |
| 方向回归加谱系内前一天变化 | 无增益 | `scores/round5_exp3__direction.csv` |
| 供体只取深文库（合成深浅混合源） | 目标深时 +1.9，目标混合时 −5.2 | `scores/round5_exp5__scores_development.csv` |
| 供体只取心脏类型 | 目标是心脏本体时持平，目标是全体时 −9 | `scores/round5_exp10__scores_development.csv` |
| 锚点去环境 RNA、只留深细胞核 | 和原样锚点无差别，取最简单的 | `scores/round5_exp6__scores_development_desoup*.csv` |
| 幅度加倍（h=2） | 一天代理上持平，两天类比上高 0.4 到 1.9；备选文件已导出，未推荐 | `scores/round5_exp8__*.csv`、`manifest_all_h2.json` |

## 文件

- `manifest.json`：推荐文件的方法、参数、随机种子、输入和外部数据哈希、验证结果。
- `method_summary_en.txt`：提交表单用的英文方法说明，列全了外部数据。
- `scores/`：本轮跑过的全部配置的分数表，没有挑选。
- 脚本在 `experiments/round5_*.py`：`round5_common.py`（内存读数据、和官方指标逐位一致的快速评分器）、`round5_anchor.py`（锚点读取）、`round5_exp1…10.py`（各批实验）、`round5_export.py`（导出）。
