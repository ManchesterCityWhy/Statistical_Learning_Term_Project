## 第二次提交的文件是怎么来的

11-25 晚到 11-26 下午，孙海铭用 Claude Code 连续做了第四到第九轮。这几轮的假设、实验、文件和分数估计都是 Claude Code 做的；孙海铭定了目标（冲测试榜第一，交上去不低于 80 分），并上传了第二次提交。

下表里的“心脏文库”指 E10.5 数据三个测序文库中的第 3 个（细胞条码后缀 \_3），94% 是心脏或血细胞类型，测序深度接近 E8.5、E9.5 的文库。“E14.5 细胞核”来自 GEO 上公开的小鼠 E14.5 心脏单细胞核数据（GSM8394736）。“bulk 趋势”是用公开的心脏 bulk RNA-seq（GSE223237 的 E9.5 和 E14.5 样本）估出的每个基因的变化方向。这两份外部数据都不在规则禁用的时间段（E9.5 之后到 E13.5）里。第四轮也出过一份候选文件，第五轮在它的基础上做，下表从第五轮列起。只有第九轮交了，没交的版本官方分数都不知道。

| 轮次 | 做法 |
| ------ | ---------------------------------------------------------------------- |
| 第五轮 | 第四轮选出的 2,000 个 E10.5 细胞（按 bulk 趋势调过类型比例），再混入 1,200 个 E14.5 细胞核 |
| 第六轮 | 3,200 个心脏文库细胞不动，混入 800 个校正过的 E14.5 细胞核 |
| 第七轮 | 5,000 个细胞：55% 是心脏文库细胞，另 45% 按 E14.5 的细胞类型组成补入（一半是真实细胞，一半是用 E14.5 细胞核改出来的合成细胞）；表达再做两项移动：从 E9.5 到 E10.5 已经朝 E14.5 方向变的基因接着往前挪，全部细胞再按 bulk 趋势挪两天的量 |
| 第八轮 | 第七轮的组成和两项移动不变，细胞全部换成真实细胞；某类细胞在 E10.5 几乎不表达的基因，每个细胞留 75% 自己的分子（UMI 计数），再按 25% 补入 E14.5 细胞核的分子 |
| 第九轮 | 第八轮的基础上，每个细胞先随机留下 85% 的分子，押的是 E12.5 的细胞测得更稀。交的是这一份 |

## 押错的判断

第七到九轮都建立在 Claude 的一个判断上：E12.5 已经从 E10.5 往 E14.5 走了一半左右，细胞组成和表达都是。依据主要是第一次提交的四项分数。做法是在本地造出各种“假设的 E12.5”，算第一次提交在每种假设下该得几分，再看哪种假设和实际得分最接近。最接近的是“心脏文库细胞加 30% 到 60% 的 E14.5 细胞核”这一类假设，三档之间分不太开，文件取了 45%。

从第二次的分数看，这个判断很可能错了：E12.5 比 Claude 判断的更接近 E10.5。第二次提交比以真实细胞为基础的条目低在 DES、MMD 和 CSS 三项，其中 MMD（细胞在主成分空间里的分布，72.4 对 75.0 到 87.4）直接受细胞组成影响。这是推断，只凭一次提交的四项分，分不清每一步各丢了多少。

用第一次提交的分数反推 E12.5，有三处弱点：

- **这种比对的方向不一定可靠**：它衡量的是假设离第一次提交有多远。凌晨 5 点多已经发现，它在“把细胞往 E14.5 方向挪多少”这一维上分不清方向，那一维因此弃用；在组成比例这一维上，它在两个答案已知的情形里选对了方向，所以留用了。下午又发现，它在混合比例这一维上同样会偏向离第一次提交更远的假设。组成比例上它是不是也偏了，当时没有再查。
- **有一项一直对不上**：这一类假设算出的第一次提交的 CSS 都是 56 到 62 分，实际是 70.5（另一类假设又高过了头，是 79 和 85）。第九轮的“留 85% 的分子”就是为了解释这一项加的，这一步本身可能也丢了分。
- **用了一个没有出处的数**：网上说“E10.5 原样提交约 69.4 分”。11-26 凌晨 1 点已经查不到出处、写了不再用，第七轮又拿它当了旁证，早上 7 点前后才撤回。靠它定下的两个取舍（都是把下面的“不变检验”的分量压低）没有重新审。

## 当时就有、但被看轻的反面证据

所谓本地检验，是用已公开的阶段打分，比如拿 E9.5 预测已知的 E10.5。其中有一项假设“E12.5 和 E10.5 心脏文库一模一样”，看每种做法在这种情形下要付多少代价，下称不变检验。原样的心脏文库在不变检验里接近满分（99.8），每多加一步改动，分数就低一截：第六轮文件 88.8，第七、八轮 82.5 到 83.0（各轮用的划分不完全相同，数只看量级）。

第七轮定权重时，不变检验只占很小的分量。理由是第一次提交的分数和上面那个 69.4 都说明 E12.5 离心脏文库很远，再加上 E10.5 到 E12.5 发育隔了两天，不可能没变。上午 10 点以后，不变检验被提到和其他检验同等的分量，但只用来拦新加的改动，已经定下的组成改动没有按它重新评价。

公开榜上以真实细胞为基础的条目 MMD 有 75 到 87，提示 E12.5 的细胞分布离 E10.5 不远。这一点上午被用来提高不变检验的分量，同样只管新改动，没有回头质疑已经做了的组成改动。

## 估分为什么差了 11 分

提交前的估计是这样来的：把榜上以真实细胞为基础的条目当作起点（当时按约 81 分算），再加上这些改动在本地检验里的增益。这里有两个问题。第一，这些改动在 E12.5 上是加分还是减分，本地没有办法检验，本地增益只说明它们在“E9.5 到 E10.5 这一步”上有效。第二，起点本身也不清楚：方法名写着用真实细胞的只有三个条目，分数是 77 到 80.6；当时把一批约 81 分的条目也算成用真实细胞的，依据只是它们的四项分和那三个相近。估计的区间只有几分宽，没有反映这两层不确定。

## 可以写进报告的教训

1. **本地验证检验不了“E12.5 具体像什么”**：拿 E9.5 预测 E10.5 这样的本地验证，能检验一种做法在已知的一步变化上灵不灵。第七到九轮的大部分改动押的是 E12.5 的具体样子，这一点本地验证不了。
2. **一次反馈撑不起反推**：只有第一次提交的四个分数时，用它们反推目标的样子很不可靠，能对上的假设太多，在有的参数上还会偏向离第一次提交更远的假设。
3. **不变检验给出的是改动的代价**：“E12.5 和 E10.5 一样”这个假设肯定不完全对，但它一直提示改动有代价。第二次提交低于以真实细胞为基础的条目，和这个提示不矛盾；不过原样的心脏文库在测试上能得多少，并不知道。
4. **两次机会里留一次给最简单的版本**：比如 E10.5 心脏文库原样，给另一次当参照。这次两次提交都改了细胞组成，没法和“不改”直接比。
5. **组成调整在本地和测试上表现不一致**：第二轮的本地实验里，调整细胞类型比例带来了主要的增益（E9.5 到 E10.5）。两次正式提交都改了组成，MMD 都偏低（69.0 和 72.4，以真实细胞为基础的条目是 75 到 87）。我们推测本地那一步的经验不一定适用于 E12.5。第一次提交有一半细胞来自测得很浅的另外两个文库，这也会拉低分数，两件事分不开。

## 报告里要和提交说明对上的几件事

- 第二次提交的方法说明写了：方法由 AI 编程助手在人的指挥下开发和运行；第一次提交的分数用在四处（选 E14.5 组成的比例；检查第七轮那项基因移动加得对不对；定性地决定不变检验和其他检验的分量；选细胞留多少分子）；也看过公开测试榜，只作大致参考。报告的说法要和它一致。
- 规则第 10 节允许用返回的分数在做好的几份预测之间选，禁止从分数里反解目标的属性再拿去造文件。第七到九轮用第一次提交的分数推断 E12.5 的细胞组成走了多远，再按推断出的 45% 定文件；第二批候选的范围也是看了第一批的结果才定的。这和第 10 节禁止的做法很接近，报告里照这个事实写。
- 赛道：规则第 9 节写明，人看了中间结果再指挥下一步的条目属于 Human Team。第四到九轮是孙海铭看着结果让 Claude Code 往下做的，按规则算 Human Team 的条目，和报告里写的赛道一致。
